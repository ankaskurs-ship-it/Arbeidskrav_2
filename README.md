# Arbeidskrav_2
Her ligger 6 *.py-filer som svarer ut oppgavene i arbeidskrav 2 i PY1010 - Grunnleggende programmering med Python høst 2026 - vår 2027.
Filene er navnet etter oppgavene.Hver fil inneholder informasjon som forklarer hva som løses i oppgaven.
Oppgavene er løst i IDE: Visual Studio Code (oppgave 1- 4) og Spyder (oppgave 5 og 6).
